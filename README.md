\# Klasifikasi Kondisi Kualitas Air pada Pembenihan Kolam Ikan Lele Menggunakan Algoritma K-Nearest Neighbors (KNN)



\## Deskripsi



Penelitian ini bertujuan untuk mengklasifikasikan kondisi kualitas air pada pembenihan kolam ikan lele menggunakan algoritma \*\*K-Nearest Neighbors (KNN)\*\*. Data kualitas air diolah berdasarkan parameter yang digunakan dalam penelitian untuk menentukan kondisi kualitas air dan membangun model klasifikasi.



Program ini mencakup tahapan pengolahan dan analisis data, mulai dari \*\*data cleaning, analisis data, pelabelan kondisi kualitas air, penentuan fitur dan target, pembagian data, standardisasi, penanganan ketidakseimbangan kelas, pemodelan menggunakan KNN, hingga evaluasi model\*\*.



\## Tujuan



Program ini digunakan untuk:



\- Mengolah dan mempersiapkan data kualitas air.

\- Menentukan label kondisi kualitas air berdasarkan kriteria yang digunakan dalam penelitian.

\- Membangun model klasifikasi menggunakan algoritma K-Nearest Neighbors (KNN).

\- Mengevaluasi performa model berdasarkan hasil klasifikasi.

\- Menentukan konfigurasi model KNN yang memberikan hasil terbaik.
